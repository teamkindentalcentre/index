❓ IBKR setup help
  1. Download and run IBKR's Client Portal Gateway on a computer (bin/run.sh root/conf.yaml or run.bat).
  2. Open https://localhost:5000 in the browser, accept the self-signed certificate warning, and log in with your IBKR credentials.
  3. Come back here, set the gateway URL above and tap Connect. On a phone, use your computer's LAN IP (e.g. https://192.168.1.20:5000) and accept the certificate on the phone once too.

Honest caveat: browsers may block cross-origin requests (CORS) from a page opened as a file or from another host. The most reliable setups are opening this page on the same machine as the gateway, or serving it from the gateway's own web root. If the connection is blocked, everything still works with manual entry — copy the values from the IBKR app.

Estimates use the Black-Scholes model (European exercise, no dividends). Premiums marked est. are theoretical and can differ from real market prices. This tool is for planning only — not financial advice.
